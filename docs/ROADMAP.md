# TeamPlay roadmap

Canonical product plan: [`PRODUCT_PLAN.md`](PRODUCT_PLAN.md) (from [issue #3](https://github.com/gennadii-TIME/TeamPlay/issues/3)).

## PR order (do not squash into one merge)

1. **#1 (this work)** — foundation, tvOS design, add/manage M3U, live TV playback.
2. **Languages** — 30 UI languages (separate PR(s)).
3. **EPG + archive detection** — XMLTV / provider guide; mark archive only when the source supports it.
4. **Archive playback + seeking** — remote pause/play/scrub/jump-to-live on a real archive-capable source.
5. **#2 Monetization** — 14-day full access, then one-time ~$4.99 StoreKit purchase.
6. Final Apple TV QA, App Store materials, release.

`main` stays review-gated — no merge without verification.
